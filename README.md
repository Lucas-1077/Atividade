# Atividade
Uma pequena atividade com objetivo de analisar os dados de uma loja fictícia, construí o arquivo python no vscode com a extensão do jupyter, em seguida pedi ao claude um codigo em html para fazer um visual e mostrar os gráficos, ele construiu o html e a api. 

# Execução 

instale as bibliotecas antes, caso não tenha ainda

pip install flask pandas matplotlib seaborn

em seguida execute o código python api.py no terminal ou pelo botão de depurar 

veja os resultado no ip gerado na sua maquina
